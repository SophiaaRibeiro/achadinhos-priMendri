# 🛍️ Achadinhos da Priscila Mendri

Site desenvolvido para reunir achadinhos, ofertas e cupons da Priscila Mendri em um único lugar.

## ✨ Funcionalidades

- 🔎 Busca por produtos
- 🏷️ Filtros por categoria
- 🎟️ Área de cupons e promoções
- 🛒 Links para diferentes marketplaces
- 📱 Interface responsiva
- ⭐ Produtos em destaque e populares
- ⚡ Seção de ofertas
- 📋 Copiar links de cupons

## 🛍️ Categorias

- Moda
- Beleza
- Casa
- Cozinha
- Acessórios
- Tecnologia

## 🎯 Objetivo

Facilitar a descoberta de produtos e ofertas selecionados pela Priscila Mendri, proporcionando uma experiência simples e organizada para encontrar achadinhos e acessar as promoções.
